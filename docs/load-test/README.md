## 2. 压测场景

模拟用户完整购物链路：

```
浏览首页 → 商品列表 → 商品详情 → 加购 → 下单 → 沙箱支付
```

每个迭代含 4 个 group、7 个 HTTP 请求、2~5s 思考时间。

## 3. 加压方案

```
并发数

     │                                        ╱  ╲
1000 ┤                                     ╱╲    ╲
     │                                   ╱  ╲    ╲
 500 ┤                                ╱╲    ╲    ╲
     │                              ╱  ╲    ╲    ╲
 100 ┤  ╱╲                       ╱╲    ╲    ╲    ╲
     │╱  ╲_____________________╱  ╲____╲____╲____╲____
     └───────────────────────────────────────────────→ 时间
      2m   3m      2m   3m    2m   3m   2m  3m  1m
```

| 阶段 | 并发 | 时长 | 累计 | 说明 |
|------|------|------|------|------|
| 1 | 0 → 100 | 2min | 2min | 热身，爬坡 |
| 2 | 100 | 3min | 5min | 稳定低负载 |
| 3 | 100 → 500 | 2min | 7min | 拉升 |
| 4 | 500 | 3min | 10min | 稳定中负载 |
| 5 | 500 → 1000 | 2min | 12min | 拉升 |
| 6 | 1000 | 3min | 15min | 稳定高负载 |
| 7 | 1000 → 2000 | 2min | 17min | 拉升到峰值 |
| 8 | 2000 | 3min | 20min | 峰值保持 |
| 9 | 2000 → 0 | 1min | 21min | 冷却 |

总时长: **21 分钟**
