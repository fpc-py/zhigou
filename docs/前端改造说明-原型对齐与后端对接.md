# 智购前端改造说明：原型对齐 + 对接后端

> 依据《智购 AI 超级商城 - 企业级可交互原型.html》对 h5-shop 前端进行改造，并扩展 BFF 聚合层透传后端已实现接口。
> 完成日期：2026-10-07

## 一、改造范围



| 模块                       | 动作                | 说明                                                                                             |
| ------------------------ | ----------------- | ---------------------------------------------------------------------------------------------- |
| `apps/bff-shop`          | 新增 6 个透传模块        | cart /order/payment /marketing/user /logistics，均走 JwtAuthGuard，userId 从 JWT 提取注入下游             |
| `apps/bff-shop`          | product 模块        | 新增 `GET /product/page` 分页透传                                                                    |
| `apps/bff-shop`          | service.config.ts | 补齐全部微服务地址与接口路径                                                                                 |
| `apps/h5-shop`           | 8 屏对齐原型           | 首页 / AI 对话 / 商品详情 / AI 比价 / AR 试穿 / 智能衣橱 / 社区 / 我的                                             |
| `apps/h5-shop`           | 交易闭环新增            | 购物车 / 结算 / 订单列表 / 订单详情 / 地址管理 / 优惠券                                                            |
| `apps/h5-shop`           | 基建                | TabBar 改 5 tab（首页 / AI / 衣橱 / 社区 / 我的）；新增 Icon / Pill / Toast；购物车改服务端接口（废弃 localStorage store） |
| `services/order-service` | 补口+修复 | 新增 `GET /order/mine`；create 调 product-service 取**真实价格与商品名**（失败回退占位）；create/cancel 支持从 `x-user-id` header 取真实用户 |
| `services/cart-service` | 修复 | 新增 `DELETE /cart/{skuId}` 删除单条接口（替代前端 count=0 的删除 hack） |

## 二、新增 / 变更接口（BFF 对外，前缀 /api）



```
GET  /product/page                商品分页（keyword/category/brand）

GET  /cart/mine                   购物车（BFF 聚合 SKU/SPU 名称、规格、价格、图）

POST /cart/add | /cart/update | /cart/clear

DELETE /cart/:skuId               删除购物车单条

POST /order/create                提交订单（requestId 幂等）

GET  /order/mine                  我的订单列表

GET  /order/:orderId              订单详情

POST /order/:orderId/cancel       取消订单

POST /payment/create              创建沙箱支付单

POST /payment/sandbox/mock-pay    沙箱模拟支付

GET  /coupon/mine                 我的优惠券

POST /discount/calculate          优惠试算（满减+券）

GET  /user/profile | PUT /user/profile

GET  /address/list | POST /address | PUT/DELETE /address/:id | PUT /address/:id/default

POST /freight/calculate           运费试算
```

## 四、后端已发现的缺口与处理



1. **订单列表接口缺失** → 已在 `order-service` 补充 `GET /order/mine?userId=`（复用 OrderMainMapper，改动极小）。

2. **order create/cancel 硬编码 userId=10001** → 已改为优先读 `x-user-id` header（BFF 自动透传），未传时回退 10001，兼容直连调试。

3. **订单金额 / 商品名是后端占位** → **已修复**：`OrderServiceImpl.create` 现在调用 product-service `/product/page` 拉取商品真实价格与 SPU 名称写入订单（`totalAmount` / `payAmount` 为真实总价）；product-service 不可用时回退占位价 100 分 / `SKU-xxx`，不影响下单主流程。

4. **购物车无删除单条接口** → **已修复**：`cart-service` 新增 `DELETE /cart/{skuId}`，BFF 与前端购物车页已改用该接口（数量减到 0 / 清空 / 删除均真实删除，不再残留 count=0 条目）。

5. **AR 试穿 / 智能衣橱 / 社区 / 全网比价渠道** 后端无对应能力 → 前端为视觉占位 / 演示数据并明确标注，不伪造接口。

## 五、启动方式



```
\# 1. 启动中间件（MySQL/Redis/RocketMQ）与 11 个 Java 微服务（各 services/\* 目录 mvn spring-boot:run）

\# 2. 启动 AI 编排（可选，对话/首页推荐需要）

cd services/ai-orchestrator && uvicorn app.main:app --port 8000

\# 3. 启动 BFF

cd apps/bff-shop && npm run start:dev

\# 4. 启动 H5

cd apps/h5-shop && npm run dev

\# 访问 http://localhost:5173，BFF 在 http://localhost:3000（vite 已配置 /api 代理）
```
