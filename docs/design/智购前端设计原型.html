设计方向说明

基于 Awwwards / Dribbble / Webflow 2025-2026 趋势与 GitHub 开源动效库实践，为智购 H5 制定的「质感 × 动效 × 叙事」升级方向。本原型只演示视觉与交互方向，不改变任何功能与后端接口。

设计令牌升级（variables.css）
  • 品牌色升级为渐变体系 #4C5CFF → #7A6BFF（渐变主按钮/头像光晕）
  • 阴影 3 层体系 + 圆角 16→20px 体系，卡片更轻盈
  • 新增动效令牌：spring 缓动 / 160-320ms 时长 / 位移幅度
  • 毛玻璃令牌：AI 输入条、搜索框、悬浮层 backdrop-blur
UI / UX 优化
  • AI 输入条玻璃拟态 + 顶部渐变流光，强化「AI 导购」心智
  • 快捷入口图标卡片 hover 上浮 + 图标微动，可点击性更明显
  • Banner 流动光晕 + 漂浮球，突出「AI 帮你买得更好」
  • 商品卡：图片区彩色渐变、价格强调、划线价、hover 抬升
  • 空状态叙事化：插画 + 人话标题 + 唯一主 CTA（衣橱空 → 拍第一件）
动效系统（全局，CSS 原语 + 可选 Motion 库）
  • 页面元素 staggered 入场（bounce-in，0.4-0.6s，错峰 60-180ms）
  • 内容感知骨架屏 shimmer（与真实卡片同形）替代 spinner
  • 按钮按压反馈（scale .93~.97 spring）、点赞弹跳、徽章 pop
  • 分段选择滑动指示器、开关 spring 滑块、数字滚动
  • AI 思考态三点呼吸、打字机光标、工具调用卡片渐入
  • 尊重 prefers-reduced-motion（全站动效可关闭）
  • 性能纪律：单屏并行动画 ≤3-4 个，主动画 ≤500ms，仅 transform/opacity
交互叙事
  • 首页问候 → AI 就绪 → 省金额动态，形成「今天省了多少」故事线
  • AI 对话展示工具调用过程（识别→入库→追问穿搭），透明可信
  • 空状态/加载/错误状态全部有叙事文案 + 明确下一步动作
落地原则（改前端必同步后端）
  • 所有视觉改动不触碰接口契约（request/response 不变）
  • 新增动效组件（Motion 或原生 CSS）按页面增量接入，逐个验证
  • 每块：实现 → type-check/build → 端到端验证 → 三件套 + 独立 commit
