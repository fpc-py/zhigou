# /review-pr

审查当前分支相对于 main/develop 的变更。

## 用法

```
/review-pr
```

## 执行步骤

1. 跑 `git diff develop...HEAD` 获取变更集
2. 按以下维度审查：
   - 安全：鉴权、越权、密钥泄露、SQL 注入
   - 正确性：事务边界、幂等、并发安全
   - 规范：命名、金额类型、日志、异常处理
   - 性能：N+1、缓存、索引
   - 测试：关键路径是否有测试
3. 输出审查报告，按严重程度分级
4. 不直接修改代码，只输出建议

## 注意事项

- 如果变更超过 500 行，建议按服务拆分审查
- 资金相关代码（订单/支付/库存）必须逐行人工确认
