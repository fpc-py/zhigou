# 安全红线

> 此文件被 CLAUDE.md 引用。每次编码、Review、改配置时必须遵守。

## 数据保护

- **禁止在日志中打印**：手机号、身份证号、地址、支付密码、银行卡号、token、完整请求体
- 日志脱敏规则：手机号保留前 3 后 4（138****1234），身份证只打星号
- 返回给前端的错误信息**不得包含**：SQL 语句、异常栈、内部类名、服务器路径

## 认证与鉴权

- 所有对外接口（除 `/auth/login`、`/auth/send-sms-code`）必须校验 JWT
- 用户只能操作自己的资源（订单、地址、购物车），service 层必须校验 `userId` 归属
- AI 工具调用必须校验 `userId` 与入参一致，否则 403
- 管理后台接口额外校验 `role=ADMIN`

## 密钥管理

- JWT_SECRET、数据库密码、第三方 API key、支付密钥：**一律走环境变量**，仓库只放 `.env.example`
- `.env` 已在 `.gitignore` 中，但每次提交前确认没有意外加入
- 历史泄露密钥**立即 rotate**，不要改个 commit message 了事

## SQL 安全

- 所有 SQL 必须参数化（MyBatis `#{}` 不用 `${}`，除非 ORDER BY 字段白名单校验）
- 动态排序字段必须白名单：只允许已定义的列名，否则抛异常
- 禁止拼接 SQL 字符串

## 安全审查清单（每次 PR 自检）

- [ ] 新接口有鉴权吗？
- [ ] 用户 ID 越权校验了吗？
- [ ] 日志里有敏感字段吗？
- [ ] 配置文件里有明文密钥吗？
- [ ] SQL 走了参数化吗？
- [ ] 输入参数做了 `@Valid` 校验吗？
