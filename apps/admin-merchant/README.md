# admin-merchant · 商家后台

智购商家端管理后台，基于 **Vue 3 + Element Plus + Vite + TypeScript**。

## 职责

- 商家登录与鉴权（`role=ADMIN` 校验）
- 商品管理：上下架、库存维护
- 订单管理：订单查询、售后审核
- 营销配置：优惠券/活动配置（规划中）

> 商家端业务实际以 **H5 商家中心**承载（apps/h5-shop 商家中心区块：经营概览/预警/补货/履约/评论/售后工作台 [0.2.17]-[0.2.75]）；本后台保持脚手架，独立商家后台（上下架/订单管理/营销配置）列入 `docs/智购开发任务差距分析报告.md` 附录 B 组。

## 启动与验证

```bash
npm install
npm run dev             # 开发
npm run build           # 构建验证
```
