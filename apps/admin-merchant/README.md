# admin-merchant · 商家后台

智购商家端管理后台，基于 **Vue 3 + Element Plus + Vite + TypeScript**。

## 职责

- 商家登录与鉴权（`role=ADMIN` 校验）
- 商品管理：上下架、库存维护
- 订单管理：订单查询、售后审核
- 营销配置：优惠券/活动配置（规划中）

> 当前为脚手架阶段，业务页按 `docs/智购开发任务差距分析报告.md` P0 清单推进（商家后台业务页：上下架 / 订单 / 营销配置）。

## 启动与验证

```bash
npm install
npm run dev             # 开发
npm run build           # 构建验证
```
